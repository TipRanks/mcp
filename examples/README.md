# Examples

Runnable sample agents built on the hosted [TipRanks MCP server](https://mcp.tipranks.com/).
Each is self-contained — clone, add your keys, run.

| Example | What it does |
|---|---|
| [due-diligence-agent](due-diligence-agent/) | Turns a ticker into a structured research memo — analyst consensus, Smart Score, financials, technicals, bull/bear case, smart-money flows, and catalysts. |

All examples authenticate with a **TipRanks MCP API key** (`tr_live_...`). Get one
at [mcp.tipranks.com/dev/signup](https://mcp.tipranks.com/dev/signup) and see the
[docs](https://mcp.tipranks.com/) for the full tool catalog and per-client setup.

> Informational only. TipRanks provides market data and analyst research for
> informational purposes — not investment, financial, legal, or tax advice.
